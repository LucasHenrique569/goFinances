# goFinances versão mobile

Versão mobile de um aplicativo para controle de transações financeiras

## Sobre

A ideia deste aplicativo é permitir que o usuário gerencie transações financeiras

## Funcionalidades

- Cadastro de transações de entrada e saída
- Listagem de todas as transações cadastradas
- Resumo com o valor total de transações de entrada e saída
- Datas das últimas transações de entrada e saída
- Resumo com o valor total arrecadado por categoria em um determinado mês e ano das transações de entrada

- Observação: na tela de cadastro, após o usuário cadastrar uma nova transação, para que a mesma apareça na tela de Listagem e na tela de Resumo é necessário recarregar o expo, derrubando o antigo e executando "npx expo start" novamente.

## Tecnologias 

- React Native
- Typescript
- Expo
- Node.js
- styed-components

## Instalação:

1. Clone o repositório:
- git clone https://github.com/LucasHenrique569/goFinances.git

2. Acesse a pasta do projeto e mude para a branch "homeVersion", que é a versão definitiva do projeto:
- cd goFinances
- git checkout -t origin/homeVersion

3. Instale as dependências:
- npm i

4. Configure a variável de ambiente presente no arquivo ".env.example"
  
5. Execute o servidor da api compatível com este projeto

6. Dentro da pasta do projeto execute:
- npx expo start
